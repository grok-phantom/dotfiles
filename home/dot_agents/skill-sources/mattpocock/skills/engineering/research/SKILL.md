---
name: research
description: "Gather primary-source evidence for a requested engineering research deliverable or explicitly delegated reading task. Focused documentation lookups are handled directly without a research workflow or unsolicited report file."
---

For explicitly delegated research, use a background agent when available and authorized. Otherwise perform the requested research directly. Save a report only when the task calls for one.

Its job:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Write the findings to a single Markdown file, citing each claim's source.
3. Save it where the repo already keeps such notes; match the existing convention, and if there is none, put it somewhere sensible and say where.
